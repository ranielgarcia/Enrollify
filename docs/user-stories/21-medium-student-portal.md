## Summary

Students view schedules, enrolled subjects, grades, balances, and can request documents (CoR).

## Persona(s)

- Student

## User Story

As a Student, I want to see my class schedules, subjects, grades, and balances, so I can track my academic progress and obligations.

## Acceptance Criteria

1. After payment confirmation, enrolled subjects appear with schedule and teacher.
2. Grades visible once published; academic standing calculated.
3. Downloadable PDFs (CoR, assessment/receipt) available when applicable.

## Dependencies

- Enrollments, ClassSchedules, EnrollmentAcademicRecords, EnrollmentPayments.
