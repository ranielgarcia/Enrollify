## Summary

Configure which misc fees apply based on course/subject attributes, with manual selection fallback.

## Persona(s)

- Cashier/Finance Officer, Registrar (during admission review)

## User Story

As a Finance Officer, I want rules to auto-apply appropriate misc fees per enrolled subjects, so irregular assessments are accurate.

## Acceptance Criteria

1. Rule engine supports per-subject fees and course-wide fees.
2. Manual override with audit reason.
