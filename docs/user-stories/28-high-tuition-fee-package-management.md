## Summary

Define tuition packages per college/course/year/regular vs irregular; support fixed packages and per-subject computations.

## Persona(s)

- Cashier/Finance Officer

## User Story

As a Finance Officer, I want to maintain tuition fee packages, so assessment can compute charges accurately.

## Acceptance Criteria

1. Create packages with applicability rules (college/course/year/regularity).
2. Versioning/effective dates; archive old packages.
3. Assessment engine selects the right package or allows manual override for irregular cases.
