## Summary

Integrate school website CMS to display news/announcements inside the student portal.

## Persona(s)

- Student, Parent, Registrar (posts originate from CMS)

## User Story

As a Student, I want to see school announcements in the portal, so I stay informed without visiting another site.

## Acceptance Criteria

1. Fetch announcements via REST API; cache and display in portal.
2. Show title, date, and content; link back to full article.
